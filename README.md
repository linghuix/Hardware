# Hardware

Some scripts and codes for sensors and boards, just to make debug and life easier.

This repository contains helper scripts, test codes, and utilities for various **sensors** and **development boards**.  
The goal is to simplify debugging and speed up prototyping in hardware-related projects.

Welcome everyone to use the scripts. If you think it is useful for you and others, please contribute and share your own useful scripts or examples!



##  Features

- Ready-to-use scripts for common hardware modules I met in projects
- Examples for quickly testing sensors  
- Lightweight and easy to extend  

* See the `README.md` files inside each folder for more details.
